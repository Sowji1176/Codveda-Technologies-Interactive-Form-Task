## About the Project

Formwise is a modern, responsive interactive form developed using HTML5, CSS3, and JavaScript as part of **Task 2: Interactive Form** for the Codveda Technologies Front-End Development Internship.

The project focuses on real-time form validation, user-friendly error messages, password strength feedback, and a clean, accessible interface.

## Key Features

* 📝 User Registration Form
* 👤 Name Validation
* 📧 Email Validation
* 📱 Phone Number Validation
* 🔐 Password Strength Indicator
* ✅ Confirm Password Validation
* ⚡ Real-Time Error Messages
* 👁️ Show/Hide Password
* 🎯 Input Focus and Blur Events
* 🎉 Success Confirmation Without Page Reload
* 📱 Responsive Design
* ♿ Accessibility-Friendly Interface
